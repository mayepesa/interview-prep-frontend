# Fundamentos de CS

Páginas de teoría con código ejecutable (sección **Fundamentos de CS** en `npm run dev`):

- [`big-o.mdx`](big-o.mdx): qué mide Big-O, complejidades comunes, tiempo vs espacio, cómo analizar código, `Map` en lugar de `find`.
- [`data-structures.mdx`](data-structures.mdx): array, objeto vs `Map`, `Set`, pila, cola (sin `shift`), lista enlazada, árboles con DFS/BFS, caché LRU.
- [`algorithms.mdx`](algorithms.mdx): cómo resolver un ejercicio en vivo, two sum, anagramas, paréntesis, búsqueda binaria, dos punteros, intervalos, recursión, memoización.

Código con tests: [`data-structures.ts`](data-structures.ts), [`algorithms.ts`](algorithms.ts), [`cs.test.ts`](cs.test.ts). Para practicar desde cero: [`exercises/`](../../exercises/README.md).
