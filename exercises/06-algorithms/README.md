# 06 · Algoritmos de screening

**Nivel:** fácil–medio · **Tiempo:** 10 min cada uno

Resuelve cada función en `starter.ts`. Para cada una: di primero la solución simple y su complejidad, luego la mejor.

| Función                        | Enunciado                                                             | Objetivo   |
| ------------------------------ | --------------------------------------------------------------------- | ---------- |
| `twoSum(nums, target)`         | Índices de los dos números que suman `target`, o `null`               | O(n)       |
| `isBalanced(text)`             | ¿Los `()[]{}` están balanceados? Ignora otros caracteres              | O(n)       |
| `binarySearch(sorted, target)` | Índice de `target` en un array ordenado, o `-1`                       | O(log n)   |
| `mergeIntervals(intervals)`    | Fusiona intervalos que se solapan (bloques de horas en un calendario) | O(n log n) |
| `chunk(list, size)`            | Parte un array en grupos de `size` (paginación)                       | O(n)       |
| `isAnagram(a, b)`              | ¿Mismas letras con la misma frecuencia?                               | O(n)       |

Las soluciones con explicación están en `src/08-cs-fundamentals/algorithms.ts`. Intenta no mirarlas.
